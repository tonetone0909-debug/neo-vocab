# Speaking Task 1 — Listen and Repeat 그림

ETS 방식: **같은 장면**을 회색으로 깔고, 그 문장이 가리키는 대상만 컬러로 칠한다.
문항마다 칠하는 대상이 달라서 **문항 수만큼 파일이 필요하다** (세트당 7장).

```
mk1_lr01.png … mk1_lr07.png     세트1 (7문항)
mk2_lr01.png … mk2_lr07.png     세트2
```

예) 문장이 "Bears, wolves, and large cats are to the right." 면
그 그림에서 곰·늑대·큰고양이만 컬러, 나머지는 회색.

파일이 없으면 "그림 준비 중" 자리표시자가 뜨고 진행은 그대로 된다.
